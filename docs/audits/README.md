# FINN audits

This folder organises the review frameworks used to challenge FINN's product experience and engineering architecture.

## Reports

The full reports remain in `docs/` to preserve their existing links:

- [UX and Product Design Audit](../UX_AUDIT.md) — live product review, interaction scenarios, accessibility, visual hierarchy and prioritised UX findings.
- [Systems Architecture, Performance and Reliability Audit](../ARCHITECTURE_AUDIT.md) — code-level architecture reconstruction, decision review, reliability risks, performance opportunities and scaling options.

## Prompt briefs

- [UX review brief](prompts/UX_REVIEW_BRIEF.md)
- [Systems architecture audit brief](prompts/SYSTEMS_AUDIT_BRIEF.md)

These are concise, reusable briefs distilled from the longer prompts used to direct the original reviews. They are not represented as verbatim session transcripts.

## Methodology

Read [Audit Methodology](../AUDIT_METHODOLOGY.md) for the rationale, evidence standards, review process, ownership boundaries and limitations.

**Important:** audit reports are dated snapshots. Always compare a finding with the current implementation before treating it as unresolved.
